# IronChat

IronChat is an Android chat application designed to connect to a third-party API for messaging.

## Features (Planned)
* Real-time chat functionality
* User authentication
* Connection to a specified third-party API for message exchange

## Project Structure
* **app/**: Main application module
    * **src/main/java**: Java source code
    * **src/main/res**: Android resources (layouts, drawables, strings, etc.)
    * **AndroidManifest.xml**: Application manifest
* **build.gradle**: Project and module-level build configurations

This project is currently under initial setup.
